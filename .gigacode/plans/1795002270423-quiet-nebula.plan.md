# План: настраиваемый цвет подзаголовка (подписи под именем агента)

## Цель
Дать пользователю возможность задавать цвет **подписи под названием агента** (subtitle).
По уточнению: правим **только настройки AI-агента** (конструктор `/agent` + экспортируемый
standalone-агент); основной дашборд не затрагиваем.

## Что именно красим
«Подзаголовок» = строка под именем агента:
- `#topSubtitle` — шапка страницы `/agent` (`templates/agent.html`);
- `#prevSubtitle` — предпросмотр агента (`templates/agent.html`);
- `#agentSubtitle` — шапка standalone-агента (`templates/agent_chat.html`).

Сейчас они получают цвет через класс `.muted` (`color: var(--muted)`, `#94a3b8`).
Добавляем отдельный CSS-var `--subtitle` и отдельный ключ палитры, который им управляет.

## Как палитра прокидывается (существующий путь)
`DEFAULT_PALETTE`/`PALETTE_KEYS` (`agent_profile.py`) → сохранение/миграция
`_migrate_palette` (`data/agent_profile.json`, `data/palettes.json`) → валидация
`web/agent.py::_apply_updates` (перебирает `PALETTE_KEYS`, ключ добавляется автоматически)
→ `templates/agent.html` (input `type=color`) → `static/agent.js` (`collect()`/`applyTheme()`/`PALETTE_INPUTS`)
→ `static/style.css` (CSS selectors) → standalone: `static/agent_chat.js` + `agent_export.py`
(копирует `style.css`/`agent_chat.js` и дампит `profile.to_dict()` как есть — код экспортёра менять не нужно).

## Правки по файлам

### 1. `rag_app/agent_profile.py`
- В `DEFAULT_PALETTE` добавить ключ (после `ui_text`):
  ```python
  "ui_subtitle": "#94a3b8",  # Интерфейс — цвет подписи под названием агента
  ```
  `PALETTE_KEYS` обновится автоматически.
- Обновить docstring и комментарий «7 colors total» → 8 (косметика).

### 2. `rag_app/templates/agent.html`
- В блоке `<h4 class="color-group">Интерфейс</h4>` добавить input после `palUiText`:
  ```html
  <label>Цвет подписи<span class="hint" data-tip="Цвет подписи (подзаголовка) под названием агента в шапке и предпросмотре.">?</span><input type="color" id="palUiSubtitle" value="{{ profile.palette.ui_subtitle }}"></label>
  ```

### 3. `rag_app/static/agent.js`
- В `collect()` → `palette` добавить `ui_subtitle: $("palUiSubtitle").value,`.
- В `applyTheme()` после установки `--ui-text` добавить:
  `root.style.setProperty("--subtitle", pal.ui_subtitle || "#94a3b8");`
- В `PALETTE_INPUTS` добавить `ui_subtitle: "palUiSubtitle",`.

### 4. `rag_app/static/style.css`
- В `:root` рядом с `--heading` добавить `--subtitle: var(--muted);`.
- Добавить правило (по id — чтобы не задеть прочий `.muted`, включая дашборд):
  ```css
  #topSubtitle, #prevSubtitle, #agentSubtitle { color: var(--subtitle); }
  ```

### 5. `rag_app/static/agent_chat.js`
- В `applyTheme()` после `--ui-text` добавить:
  `root.style.setProperty("--subtitle", pal.ui_subtitle || "#94a3b8");`

### 6. Бэкенд/экспорт — без изменений
`_apply_updates` валидирует новый ключ через `PALETTE_KEYS`+`_COLOR_RE`; `agent_export.py`
никаких правок не требует.

## Совместимость
- Старые `data/agent_profile.json`/`data/palettes.json` без `ui_subtitle` — `_migrate_palette`
  дополнит дефолтом `#94a3b8`, т.е. внешний вид не меняется.
- Некорректный hex игнорируется (остаётся дефолт), как и для других ключей.
- Старые экспортированные архивы: fallback `|| "#94a3b8"` сохраняет прежний вид.
- Дашборд не затронут: `--subtitle` по умолчанию = `var(--muted)`, id-селекторы там не встречаются.

## Тесты (`tests/test_agent.py`)
- Обновить существующие (иначе упадут из-за нового ключа):
  - `test_profile_palette_colors_roundtrip` — в ожидаемый dict добавить `"ui_subtitle"`.
  - `test_palettes_save_list_delete` — в `set(saved["Brand"]["colors"])` добавить `"ui_subtitle"`.
- Добавить:
  - roundtrip: POST `{"palette": {"ui_subtitle": "#abcdef"}}` → GET профиля → `== "#abcdef"`;
  - дефолт без сохранения: `palette["ui_subtitle"] == "#94a3b8"` (проверка миграции);
  - плохой hex: `{"ui_subtitle": "nope"}` → остаётся `#94a3b8`;
  - экспорт: после сохранения цвета проверить `palette["ui_subtitle"]` в `data/agent_profile.json` из zip.

## Проверка
**Автотесты:**
```
python -m pytest tests/test_agent.py -q
```
(при желании `python -m pytest -q`).

**Вручную** (`python run.py`, открыть `/agent`):
1. «2. Цвета → Интерфейс» появился input «Цвет подписи» (по умолчанию `#94a3b8`).
2. Выбрать заметный цвет → подпись под именем агента в шапке и предпросмотре перекрашивается live.
3. «Сохранить настройки» → перезагрузить `/agent` → цвет сохранился.
4. Палитры: сохранить палитру → поменять цвета → выбрать палитру из списка → цвет подписи восстановился.
5. «Экспорт приложения» → запустить standalone → подпись использует `ui_subtitle`.
