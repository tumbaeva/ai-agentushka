# План: упрощение цветов AI-агента (3 группы × 7 цветов) + сохранение палитр

## Цель

Заменить запутанную модель цветов (accent / accent-2 / бренд-цвет / «Корпоративная») на простые
**три группы** («Пользователь», «Агент», «Интерфейс») с понятными названиями и добавить
**сохранение палитр** (именованные наборы). Никаких «акцентов» и «корпоративных» в интерфейсе не остаётся.

## Новые цвета (ровно 7)

| Группа | Настройка | Ключ | Что окрашивает | По умолчанию |
|---|---|---|---|---|
| Пользователь | Цвет поля | `user_bg` | фон сообщений пользователя | `#0ea5e9` |
| Пользователь | Цвет шрифта | `user_text` | текст сообщений пользователя | `#ffffff` |
| Агент | Цвет поля | `agent_bg` | фон ответов агента **и** эмблемы/лого | `#7c3aed` |
| Агент | Цвет шрифта | `agent_text` | текст ответов агента | `#ffffff` |
| Интерфейс | Цвет фона | `ui_bg` | фон страницы и панелей/окна чата | `#0f172a` |
| Интерфейс | Цвет поля | `ui_field` | фон кнопок (в т.ч. «Отправить») и полей ввода, кнопок-вопросов | `#0ea5e9` |
| Интерфейс | Цвет шрифта | `ui_text` | основной текст, заголовки, имя/подзаголовок агента | `#e2e8f0` |

Единый вид на странице агента строится **только** из этих 7 цветов. `theme_mode` (Тёмная/Светлая/Авто)
оставляем — он переключает лишь нейтральные оттенки рамок/подложек и не мешает 7 цветам.

## Данные

- **`rag_app/agent_profile.py`**: `DEFAULT_PALETTE` = 7 ключей выше. Удалить из `AgentProfile` поля
  `brand_color` и `theme_preset`. `from_dict` — терпимый merge + **миграция старых ключей**:
  `accent→ui_field`, `accent2→ui_text`(или `ui_field`), `bg→ui_bg`, `panel→ui_bg`, `text→ui_text`,
  `user_color→user_bg`, `agent_color→agent_bg`, `chip_color→ui_field`. Так старые
  `data/agent_profile.json` продолжают читаться.
- **Библиотека палитр**: новый файл `data/palettes.json` — список `{ "name": str, "colors": {7 ключей} }`.
  Функции `load_palettes(settings)` / `save_palette(settings, name, colors)` / `delete_palette(settings, name)`
  (в `agent_profile.py`). Путь — `settings.data_path / "palettes.json"`.

## Backend — `rag_app/web/agent.py`

- `PALETTE_KEYS = ("user_bg","user_text","agent_bg","agent_text","ui_bg","ui_field","ui_text")`.
- `_apply_updates`: валидировать hex-цвета для этих ключей (убрать accent/brand/theme_preset).
- `favicon`: цвет берётся из `agent_bg` (вместо `brand_color`).
- Новые эндпоинты: `GET /api/agent/palettes` (список имён), `POST /api/agent/palettes` (`{name, palette}` —
  сохранить и, опционально, применить), `DELETE /api/agent/palettes/<name>`.

## CSS — `rag_app/static/style.css`

- Ввести переменные-хуки: `--user-bg, --user-text, --agent-bg, --agent-text, --ui-bg, --ui-field, --ui-text`
  (и `--panel = --ui-bg`).
- Обновить **агент-специфичные** селекторы:
  - `.chat-bubble.user { background: var(--user-bg); color: var(--user-text); }`
  - `.chat-bubble.bot { background: var(--agent-bg); color: var(--agent-text); }`
  - `.chat-bubble.bot summary/.cite` — контрастно относительно `--agent-text`.
  - `.agent-avatar { background: var(--agent-bg); color: var(--agent-text); }`
  - `.starter-chips .chip { background: var(--ui-field); color: #fff; }`
  - Кнопки/поля ввода — фон `var(--ui-field)`; заголовки/имена/`topbar h1` — `var(--ui-text)`;
    фон страницы/панелей — `var(--ui-bg)`/`var(--panel)`.
- **Дашборд не ломать**: не трогать `.msg.*` (вкладка «Чат» дашборда) и дефолты в `:root`.

## Frontend

- **`rag_app/static/agent.js`**:
  - `collect()` — палитра из 7 новых полей; убрать corporate/бренд-логику.
  - `applyTheme(p)` — установить 7 новых переменных **и** смапить легаси-переменные
    (`--bg,--panel,--text,--input,--accent,--accent-2,--heading,--user-color,--agent-color,--chip-color`)
    из новых, чтобы общие селекторы (кнопки, ссылки, заголовки) выглядели корректно.
  - Отрисовка трёх групп; блок **«Палитры»**: поле имени + кнопки «Сохранить / Загрузить / Удалить» и список
    (через новые эндпоинты).
- **`rag_app/static/agent_chat.js`**: `applyTheme()` — те же 7 переменных (+ маппинг легаси).

## Шаблон — `rag_app/templates/agent.html`

- Заменить секцию «2. Тема и цвета» на три группы с понятными подписями:
  - **Пользователь**: «Цвет поля», «Цвет шрифта».
  - **Агент**: «Цвет поля (ответы и лого)», «Цвет шрифта».
  - **Интерфейс**: «Цвет фона», «Цвет поля (кнопки и поля)», «Цвет шрифта».
  - Оставить выпадающий «Режим» (Тёмная/Светлая/Авто).
  - Добавить блок **«Палитры»** (имя + Сохранить/Загрузить/Удалить + список).

- `rag_app/app_template/README.md`: убрать строку с `{{BRAND_COLOR}}`/«Бренд-цвет».

## Проверка (end-to-end)

1. `python -m pytest` — всё зелёное.
2. `python run.py` → `/agent`: задать 7 цветов (предпросмотр чата меняется), сохранить палитру, загрузить, удалить.
3. **Экспорт** → распаковать → `Запустить агента.bat`: применились цвета пользователя/агента/интерфейса,
   эмблемы, кнопок-вопросов и favicon.
4. Регресс: дашборд и его вкладка «Чат» выглядят как раньше.

## Риски

- `style.css` общий для дашборда и агента → маппинг легаси-переменных обязателен, иначе отвалятся кнопки/ссылки.
- Обратная совместимость: старые профили (`accent`, `agent_color`, `brand_color`, `theme_preset`) — миграция ключей.
- Контраст текста: у пузырей/кнопок текст может оказаться нечитаемым — при желании добавить авто-подбор (белый/чёрный).
- favicon: цвет берём из `agent_bg`, синтез SVG как раньше.
