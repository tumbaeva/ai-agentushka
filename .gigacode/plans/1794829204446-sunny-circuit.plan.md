# План: дополнение «AI-агент» (конструктор + экспорт самостоятельного приложения)

## Цель

Добавить в RAG Dashboard коммерческую надстройку — **конструктор AI-агента**: вкладка «AI-агент», где
пользователь настраивает брендинг/тему/стиль ответа, загружает документ-базу и по кнопке **экспортирует
самостоятельное приложение-агента** (zip). Экспортированное приложение — **только чат** (без дашборда),
с лучшими подобранными настройками из основного проекта.

## Подтверждённые решения

1. **Формат:** конструктор + экспорт zip на базе текущего Flask-кода.
2. **Обновление документа:** загрузка нового `knowledge_base.md` / `.md` / `.txt` / `.docx` + авто-переиндексация.
3. **Стиль ответа:** пресеты (8 шт.) + кастомный системный промпт + temperature + длина.
4. **UI-кастомизация:** полный набор (имя, подзаголовок, лого, favicon, темы/кастом-палитра, размеры шрифта/кнопок, компактный режим, ширина сайдбара, приветствие, стартовые вопросы, показ источников, RU/EN).
5. **Длина ответа:** `short`→~300 токенов, `medium`→**без `max_tokens`**, `long`→~1600.
6. **Экспорт:** сохраняет эндпоинт обновления базы знаний в рантайме.
7. **Экспортированное приложение:** только чат, использует текущие (лучшие подобранные) `Settings` основного проекта.
8. **Корпоративная тема:** один пресет — акцент = выбранный бренд-цвет, парные оттенки вычисляются автоматически.

## Ключевой контекст (проверено по коду)

- `rag_app/__init__.py` → `create_app()` регистрирует `api_bp`, `kb_bp`, `pages_bp`; `AppContext` держит `settings, index, retriever, chat, ingestion, builder`.
- `rag_app/config.py` — dataclass `Settings` (плоские скаляры), `save_settings()`, свойства `kb_path`/`data_path`.
- `rag_app/generation.py` — константа `SYSTEM_PROMPT`, `build_prompt(...)`, `generate_answer(...)`.
- `rag_app/ingestion.py` — `save_upload()` (`.md/.txt/.markdown`, файл `knowledge_base.md` заменяет базу).
- Образец отдельной страницы/блюпринта: `rag_app/web/kb_builder.py` + `templates/kb_builder.html` + `static/kb_builder.js`.
- Тема — CSS-переменные в `:root` в начале `rag_app/static/style.css`; ширина раскладки захардкожена (`480px`).
- Тесты: pytest, `python -m pytest`; каждый тест-файл сам создаёт `Settings(tmp_path=...)` + `create_app()`.

## Новые модули

### `rag_app/agent_profile.py`
`AgentProfile` (dataclass) + `to_dict()`/`from_dict()` (терпимо к неизвестным ключам) + `load_agent_profile()`, `save_agent_profile()`, `profile_path(settings)` → `data/agent_profile.json`.
Поля: брендинг (`agent_name`, `subtitle`, `logo_type` emoji|initials|file, `logo_emoji`, `logo_initials`, `logo_file`, `favicon_*`), тема (`theme_mode` dark|light|auto, `theme_preset`, `brand_color`, `palette{accent,accent2,bg,panel,text}`, `font_size` S|M|L, `button_size`, `radius`, `compact`, `sidebar_width`), раскладка (`welcome_message`, `starter_questions`, `show_sources`, `ui_language` ru|en), стиль (`style_id`, `custom_prompt`, `temperature`, `length` short|medium|long).
Добавить в `config.py` свойство `Settings.agent_profile_path`.

### `rag_app/agent_styles.py`
`ANSWER_STYLES` — 8 пресетов (id, `label_ru`, `label_en`, `instruction`, `temperature`, `length`):
`business`, `friendly`, `humorous`, `concise`, `expert`, `explain_simple`, `legal`, `informal_emoji`.
`get_style(id)` (fallback → business) и
`compose_system_prompt(base, style_id, custom_prompt="", length="medium") -> str` —
всегда сохраняет базовые правила обоснованности (`SYSTEM_PROMPT`: только по контексту, не выдумывать, ссылаться на источники),
затем добавляет `custom_prompt` (если задан) либо `instruction` пресета, плюс фразу о длине.
`LENGTH_TOKENS = {"short": 300, "medium": None, "long": 1600}`, `tokens_for_length(length)`.

### `rag_app/agent_export.py`
`build_standalone_zip(settings, profile) -> bytes`:
1. Скопировать весь пакет `rag_app/` (кроме `__pycache__/` и `app_template/`) под `rag_app/...`.
2. Наложить скелет `rag_app/app_template/` (подстановка токенов `{{AGENT_NAME}}`, `{{SUBTITLE}}`, `{{BRAND_COLOR}}`, `{{LANG}}`): `run.py`, `run.bat`, `requirements.txt`, `README.md`, `.env.example` (последние — в корень архива).
3. Записать `data/agent_profile.json` из профиля.
4. Записать `data/settings.json` (все поля `Settings` кроме 3 секретов) — так переносятся лучшие подобранные настройки.
5. Записать `docs/knowledge_base.md` (если есть) и `data/agent_assets/*`.
6. **Не включать** `.env`. Помощник `_slug(name)` для имени файла.

### `rag_app/app_template/` (статический скелет)
`run.py` (`create_app(standalone=True)`), `run.bat`, `requirements.txt` (копия), `README.md`, `.env.example`.

## Изменения в существующих файлах

- **`rag_app/generation.py`:** `build_prompt(..., system_prompt=None)` → `system_prompt or SYSTEM_PROMPT`;
  `generate_answer(..., system_prompt=None, max_tokens=None)` → прокинуть system_prompt и добавить `max_tokens` в `create(...)` только когда задан. Обратная совместимость (старые вызовы без параметров не меняются).
- **`rag_app/ingestion.py`:** в `save_upload()` поддержать `.docx` (через `loaders._docx_paragraphs`); путь для неизвестных расширений по-прежнему → ошибка/400. Обновить текст ошибки.
- **`rag_app/web/agent.py`** (новый блюпринт `agent_bp`, по образцу `web/kb_builder.py`):
  - `GET /agent` → `render_template("agent.html", ...)`.
  - `GET/POST /api/agent/profile` (merge + валидация/clamp: temperature 0–1, enum-и, диапазоны, сохранение).
  - `GET /api/agent/styles`, `POST /api/agent/prompt/preview` (возвращает собранный системный промпт).
  - `POST /api/agent/document` (upload → `ctx.rebuild()`, как в `api.py::upload_document`).
  - `POST /api/agent/chat/message` (чат с применением стиля: `generate_answer(..., system_prompt=compose_system_prompt(...), max_tokens=tokens_for_length(...), temperature=profile.temperature)`; история в `ctx.chat`).
  - `POST /api/agent/asset` + `GET /api/agent/asset/<name>` (лого/favicon в `data/agent_assets/`, валидация расширений и имени).
  - `GET /api/agent/favicon` (загруженный файл или синтезированный SVG из emoji/инициалов + бренд-цвет).
  - `POST /api/agent/export` → `send_file(BytesIO(zip), mimetype="application/zip", as_attachment=True, download_name="{slug}-agent.zip")`.
- **`rag_app/__init__.py`:** `create_app(settings=None, *, standalone=False)`; всегда регистрировать `agent_bp`;
  при `standalone=True` — только `agent_bp` + корневой маршрут рендерит `agent.html` (чат-онли, без дашборда); иначе зарегистрировать `api_bp`, `kb_bp`, `pages_bp` **и** `agent_bp`. `ctx.profile = load_agent_profile(settings)`.
- **`rag_app/templates/agent.html`** (новый): сайдбар — Брендинг, Тема/палитра, Размеры/раскладка, Стиль ответа, Язык, Приветствие/подсказки, Источники, Загрузка документа, кнопка Экспорт; справа — живое превью чата (лого, приветствие, чипы-вопросы), превью системного промпта, реальный ввод чата.
- **`rag_app/static/agent.js`** (новый): загрузка профиля; `applyTheme()` устанавливает CSS-переменные и `data-*`-атрибуты (`[data-theme]`, `--font-size`, `--sidebar-w`, compact); живое превью; пресеты тем (корпоративная = акцент из `brand_color`); загрузка лого; сохранение; превью промпта; список стартовых вопросов; i18n-подписи; экспорт (fetch blob → download); загрузка документа → показ `rebuilt.chunks`.
- **`rag_app/static/style.css`** (правки, дашборд не меняется): добавить `--font-size`, `--sidebar-w`, блок `html[data-theme="light"]`, классы compact и вариантов размера кнопок; `body { font-size: var(--font-size) }`, `.layout { grid-template-columns: var(--sidebar-w) 1fr }`.
- **`rag_app/templates/index.html`:** ссылка-вкладка `<a href="/agent" class="tab">AI-агент</a>`.

## Проверка (end-to-end)

1. `python -m pytest` — всё зелёное (старые + новые).
2. `python run.py` → `http://127.0.0.1:5555`, вкладка **AI-агент**: живое превью темы/названия, выбор стиля + кастомный промпт, загрузка `.md` (проверить число чанков), сохранение.
3. **Экспорт** → скачать zip → распаковать в чистую папку → `run.bat` (или `python run.py`).
4. Убедиться: приложение открывается как **чат-онли** агент с заданным брендингом и стилем, подхватывает лучшие настройки (модель/чанки/режим) из `data/settings.json`; с валидным `GIGACHAT_API_KEY_SECRET` в `.env` — генерирует ответы, без него — стартует и отдаёт фрагменты/подсказку.
5. Регресс: исходные вкладки дашборда и `/kb-builder` работают; поведение `/api/chat/message` не изменилось.

## Риски

- Оффлайн-запуск экспорта: нужны зависимости и первая загрузка моделей (интернет) — отразить в README.
- Добавочный keyword-параметр `standalone` не ломает существующих вызовов `create_app` (проверено: вызывается с одним аргументом).
- `.docx` в ingestion не должен ломать тест отклонения неизвестного расширения.
- Часть OpenAI-совместимых эндпоинтов может не принимать `max_tokens` — параметр условный, при `medium` не отправляется.
- Безопасность: санитизация имён в `data/agent_assets/`, корректный mimetype favicon.
