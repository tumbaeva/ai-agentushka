# План: цвета агента — проверка и завершение

## Статус: реализация уже в коде

Запрошенные изменения присутствуют в файлах (проверено чтением):

- **Кнопка «Удалить» — красная** — `rag_app/static/style.css`:
  `.btn-danger, #btnPaletteDelete { background: var(--err) !important; color:#fff !important; }`
  и `.agent-page .del, .agent-page .q-del, … { color: var(--err) !important; }`
- **Кнопки-вопросы и «Отправить» = цвета пользователя** — `rag_app/static/style.css`:
  `.starter-chips .chip { background: var(--user-bg); color: var(--user-text); }`
  `.chat-input button { background: var(--user-bg); color: var(--user-text); }`
  (охватывает и превью конструктора `.agent-preview`, и экспорт `.agent-shell`)
- **Таблица цветов (3 группы, 7 цветов)** — `rag_app/agent_profile.py` (`DEFAULT_PALETTE`:
  `user_bg, user_text, agent_bg, agent_text, ui_bg, ui_field, ui_text`), `rag_app/templates/agent.html`
  (секция «2. Цвета»: группы «Пользователь» / «Агент» / «Интерфейс» + блок «Палитры»),
  `rag_app/static/agent.js` (`collect()`/`applyTheme()`), `rag_app/static/agent_chat.js` (`applyTheme()`).
- **Эмблема/лого = цвета агента** — `.agent-avatar { background: var(--agent-bg); color: var(--agent-text) }`.
- **Палитры** — `data/palettes.json`, API-эндпоинты в `rag_app/web/agent.py`.

## Единственное, что нужно сделать пользователю

Правки в CSS/JS/шаблоне «вшиваются» в экспортируемый агент только при экспорте.

## Проверка

1. Перезапустить основной проект: `Ctrl+C` → `python run.py`.
2. Открыть `http://127.0.0.1:5556/agent`, обновить **Ctrl+F5** (сброс кэша `agent.js`/`style.css`).
3. Вкладка **AI-агент → 2. Цвета**: убедиться, что цвета сгруппированы в три таблицы
   (Пользователь / Агент / Интерфейс), кнопки-вопросы и «Отправить» в превью — цвета пользователя,
   «Удалить» палитры — красная; задать цвета и нажать **«Сохранить настройки»**.
4. Нажать **«Экспорт приложения»**, распаковать zip в новую папку, запустить `Запустить агента.bat`
   и убедиться, что в готовом агенте кнопки-вопросы и «Отправить» используют цвета пользователя,
   ответы и эмблема — цвета агента, удаление — красное.
5. `python -m pytest` — должно быть зелёным.
