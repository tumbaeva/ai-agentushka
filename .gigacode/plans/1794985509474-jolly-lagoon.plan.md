# План: упростить цвета конструктора AI-агента (7 цветов + палитры)

## Цель

Заменить текущую цветовую модель (accent/accent2/bg/panel/text/user_color/agent_color/chip_color + brand_color + theme_preset) на **7 понятных цветов в трёх группах**, добавить **сохранённые палитры** (сохранить/загрузить/удалить) и уточнить назначение цветов для кнопок.

## Цветовая таблица (итоговая, 7 цветов)

| Группа | Поле в профиле | Что окрашивает |
|---|---|---|
| Пользователь | `user_bg` | Фон сообщений пользователя; **фон кнопок-вопросов и кнопки «Отправить»** |
| Пользователь | `user_text` | Текст сообщений пользователя; **текст кнопок-вопросов и «Отправить»** |
| Агент | `agent_bg` | Фон ответов агента; **эмблема/лого/аватар агента**; **favicon** |
| Агент | `agent_text` | Текст ответов агента |
| Интерфейс | `ui_bg` | Фон страницы **и** панелей/карточек/окна чата (один цвет) |
| Интерфейс | `ui_field` | Фон обычных кнопок и полей ввода |
| Интерфейс | `ui_text` | Основной текст интерфейса, заголовки, имя/подзаголовок агента |

## Подтверждённые решения
- Кнопки-вопросы и «Отправить» = цвета группы **Пользователь** (фон `user_bg`, текст `user_text`).
- Кнопки **«Удалить»** во всём интерфейсе агента — **красные**.
- Переключатель **Тёмная/Светлая/Авто — убрать**.
- Убрать «Акцент», «Акцент-2», «Корпоративная», бренд-цвет из UI и профиля (favicon → `agent_bg`).
- Добавить библиотеку **сохранённых палитр** (имя + список; загрузить/удалить).
- Интерфейс — простой, без жаргона.

## Файлы

### 1. `rag_app/agent_profile.py`
- `DEFAULT_PALETTE` = `{user_bg, user_text, agent_bg, agent_text, ui_bg, ui_field, ui_text}` (тёмные разумные значения по умолчанию).
- Удалить поля `brand_color`, `theme_preset` из `AgentProfile`. `theme_mode` — тоже удалить.
- `from_dict` — оставить терпимым к неизвестным ключам + **миграция старых ключей**: `user_color→user_bg`, `agent_color→agent_bg`, `accent→ui_field`, `bg→ui_bg`, `text→ui_text`, `panel→ui_bg`, `chip_color→user_bg`, `accent2→ui_field`, `brand_color→(игнор)`, `theme_preset→(игнор)`, `theme_mode→(игнор)`.

### 2. Хранилище палитр — `data/palettes.json`

- Хелперы в `agent_profile.py`: `load_palettes(settings)`, `save_palette(settings, name, palette)`, `delete_palette(settings, name)`.

### 3. `rag_app/web/agent.py`

## Риски
- Общий `style.css` используется и дашбордом — не сломать его (меняем точечно, `:root` по умолчанию сохраняем).
