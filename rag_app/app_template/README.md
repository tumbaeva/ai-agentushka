# {{AGENT_NAME}}

{{SUBTITLE}}

Автономный AI-агент по базе знаний: умный поиск по документам и генерация
ответов со ссылками на источники. Работает **локально на одной машине**.

## Быстрый старт

1. **Сначала распакуйте архив**: правый клик по `.zip` → «Извлечь всё…».
   Запускать прямо из архива (окна просмотра zip) нельзя — приложение не заработает.
2. В распакованной папке дважды щёлкните **«Запустить агента.bat»**.

- При первом запуске скрипт создаст ярлык **{{AGENT_NAME}}** на рабочем столе,
  подготовит окружение `.venv`, установит зависимости и запустит агента в браузере.
- Дальше можно запускать просто с ярлыка на рабочем столе (или тем же файлом).
- Ярлык создаётся один раз и указывает на эту папку — не перемещайте её после запуска.

Вручную:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

## Первый запуск

1. В архиве уже есть собранный индекс (`data/index/`) и база знаний — при старте
   поиск готов сразу (если база не менялась).
2. Ключи GigaChat (Cloud.ru) уже в файле `.env` — проверьте или замените при
   необходимости. Без ключа поиск работает, а агент отдаёт контакты организаторов.
3. Агент откроется в браузере автоматически. Его адрес напечатан в чёрном окне
   (обычно `http://127.0.0.1:5555`). Если браузер не открылся — скопируйте адрес
   из окна и вставьте в браузер вручную. Окно не закрывайте, пока работаете.

> Первый запуск может быть долгим: скачивается модель эмбеддингов и строятся
> эмбеддинги. Нужен интернет для первой загрузки весов.

## База знаний

База знаний — файл `docs/knowledge_base.md`, индекс лежит в `data/index/`.
Чтобы обновить базу, замените файл и пересоберите индекс (или запросите новый
архив у поставщика).

## Настройки

- Брендинг (название, подзаголовок, логотип), тема, размеры интерфейса и стиль
  ответа — в `data/agent_profile.json`.
- Параметры поиска/моделей — в `data/settings.json`.
- Секреты — в `.env` (не коммитится).
