# RAG Dashboard

Локальный RAG-помощник по базе знаний конкурса детского рисунка
«Мир науки глазами детей — 2026» (АлтГПУ). Продукт для организаторов
образовательных конкурсов: умный поиск по документам + генерация ответов
со ссылками на источники.

Работает **локально на одной машине** (Windows), без облака и мульти-тенантности.

## Возможности

- **5 режимов поиска:** векторный, BM25, гибридный (RRF), multi-query, multi-query + rerank.
- **Чанки строятся из `docs/knowledge_base.md`** — единого источника знаний.
- **Управление базой знаний** через веб-интерфейс: добавление `.md`/`.txt` документов и удаление разделов с авто-переиндексацией.
  (Конвертация `.docx`/`.pdf` в базу знаний выполняется отдельным инструментом.)
- **Чат с историей** диалогов (сохраняется между перезапусками, SQLite).
- **Цитаты источников:** каждый ответ показывает фрагменты-источники с подсветкой и разделом документа.
- **Аналитика качества:** метрики поиска (hit@k, recall@k, precision@k, doc_acc@k, doc_precision@k, mrr@k) и тепловая карта.
- **Умный чанкинг** по заголовкам/абзацам с метаданными (раздел, тип документа).
- **Работа с запросом:** переформулировка, синонимы ниши, опционально HyDE.
- **Настраиваемое слияние и rerank:** веса BM25/вектора, RRF k, cross-encoder reranker.
- **Конструктор AI-агента:** вкладка «AI-агент» — брендинг (название, лого, favicon), 7 настраиваемых цветов в трёх группах (Пользователь / Агент / Интерфейс), библиотека палитр, размеры интерфейса, стиль ответа (8 готовых стилей + редактируемый системный промпт), обновление документа и **экспорт самостоятельного приложения-агента** (chat-only, zip).

> 📖 Подробное руководство: **[HELP.md](HELP.md)** (вкладки, настройки, режимы, метрики, API, решение проблем).

## Быстрый старт

```bat
run.bat
```

Скрипт создаст виртуальное окружение `.venv`, установит зависимости и запустит
приложение на `http://127.0.0.1:5555`.

Вручную:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

## Первый запуск

1. Приложение соберёт индекс по документам из `docs/` автоматически.
2. Откройте вкладку **Настройки** и укажите секреты GigaChat (key ID / secret) —
   без них поиск работает, но генерация ответов недоступна.
3. Выберите embedding-модель (по умолчанию лёгкая MiniLM; для лучшего качества
   русского — **BGE-M3**) и нажмите **«Перестроить индекс»**.

## Конфигурация

Секреты хранятся в `.env` (не коммитится). Пользовательские настройки —
в `data/settings.json`. Модели кэшируются в `data/models_cache/`.

| Переменная | Назначение |
|---|---|
| `GIGACHAT_API_KEY_ID` / `GIGACHAT_API_KEY_SECRET` | ключи GigaChat (Cloud.ru) |
| `HF_TOKEN` | токен HuggingFace для gated-моделей (FRIDA) |
| `RAG_KB_DIR` | путь к папке с документами (по умолчанию `docs/`) |
| `LLM_MODEL` / `LLM_BASE_URL` | модель и адрес LLM |

## Структура проекта

```
app.py                 # тонкая обёртка: create_app()
run.py                 # лаунчер (открывает браузер)
rag_app/
  config.py            # настройки и реестр моделей
  loaders.py           # парсеры .docx/.pdf/.md/.txt
  chunking.py          # heading-aware чанкинг
  embeddings.py        # загрузка моделей + кэш
  index.py             # FAISS + BM25 + снэпшоты
  query_transform.py   # рерайт/синонимы/HyDE
  retrieval.py         # режимы поиска
  generation.py        # промпты, ответы, цитаты
  agent_profile.py     # профиль AI-агента (брендинг, тема, стиль)
  agent_styles.py      # готовые стили ответа + сборка системного промпта
  agent_export.py      # сборка standalone-приложения (zip)
  app_template/        # скелет экспортируемого приложения (run.py, run.bat, README)
  eval.py              # метрики + heatmap
  chat_store.py        # SQLite-история чатов
  ingestion.py         # загрузка/удаление документов
  web/api.py           # JSON API
  web/agent.py         # блюпринт «AI-агент» + экспорт
  web/pages.py         # HTML-страницы
  templates/index.html
  static/style.css, app.js
docs/                  # база знаний
data/                  # настройки, индекс, чаты, кэш моделей (не коммитится)
tests/                 # pytest
```
